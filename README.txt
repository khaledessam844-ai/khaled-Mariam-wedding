Khaled & Mariam — Free Interactive Wedding Invitation

HOW TO PUBLISH FOR FREE WITH GITHUB PAGES
1. Sign in at https://github.com and create a new PUBLIC repository named wedding-invitation.
2. Upload BOTH files from this folder: index.html and invitation.jpg (to the repository root).
3. Go to repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
5. After publishing, your link will usually be https://YOUR-USERNAME.github.io/wedding-invitation/

The invite opens an animated envelope on tap, plays a soft synthesized melody, and displays the original artwork and map button.
Music requires a tap to start on iPhones. The music is generated by the browser and does not need an audio file.
